# Homework Test — Vela Website (Keyboard Product)

**DF LABS - HOMEWORK TEST**

---

## Tugas

Bangun bagian kecil dari website **Vela** (brand custom keyboard) berdasarkan dokumen *Solutioning Product Service — Vela* yang kami kirim bersama file ini. Dokumen solutioning ditulis dalam bahasa Inggris — sama seperti spec project sungguhan yang akan kamu terima. Hal yang perlu dikerjakan berupa:

1. **Satu API: GET list produk** — sesuai bagian E dokumen solutioning: mengembalikan produk dari database (di-seed dari Lampiran), mendukung fitur **pencarian** dan **filter**.
2. **Halaman katalog** — menampilkan produk dengan **memanggil API GET-mu sendiri**, lengkap dengan cari + filter kategori. **Desainnya WAJIB mengikuti anchor di folder vela-assets/**:
   - `design-page.png` — desain resmi halaman Vela. Ikuti bahasa desainnya: nav, tipografi, warna, jarak, rasa gelap-premium-minimalnya. Katalogmu harus terlihat seperti halaman lain dari website yang sama.
   - `product-*.png` — gambar produk resmi, pakai ini sebagai gambar produkmu.
   - Tidak harus piksel-sempurna — tapi kalau halamanmu disandingkan dengan `design-page.png`, harus terasa satu website.

## Aturan

- Stack website bebas. Kerjakan di repo milikmu sendiri.
- Database: **PostgreSQL dianjurkan** (seed siap pakai); SQLite juga boleh.
- **Wajib pakai AI**, bebas pakai Claude, Codex, GLM, or anything else. ChatGPT / Claude versi chat (gratis) juga cukup untuk project ini.
